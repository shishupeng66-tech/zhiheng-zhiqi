# 知衡智企 自动剪辑 V1 · 真实成片测试与验收方案

> 版本:V1.0
> 制定日期:2026-08-26
> 状态:**测试方案(本轮不修改代码 / 不生成视频 / 不 push)**
> 目标:不是证明"能生成 MP4",而是判断**成片能否达到企业抖音/视频号可用水平**

---

## 0. 一句话目标

用 **100+ 企业真实拍摄素材**,通过「自动剪辑工作台 → LLM 脚本 → MoneyPrinterTurbo 成片 → 人工评分」闭环,建立一条**可复现、可归因、可迭代**的验收基线,最终产出「剪出来就能发」的企业短视频。

## 1. 第一轮 5 个测试主题(不同风格全覆盖)

> 场景:饮料生产 / 饮料代工制造企业。5 条覆盖 5 种内容形态,不重复。

| # | 形态 | 主题 | 时长 |
|---|---|---|---|
| T1 | 知识科普 | 无菌冷灌装到底先进在哪? | 30–45s |
| T2 | 工厂实力 | 一条生产线一天能出多少瓶? | 30–45s |
| T3 | 避坑/行业建议 | 饮料代工选厂,5 个坑别踩 | 30–45s |
| T4 | 产品/案例 | 客户案例:从代工到自有品牌的第 1 步 | 30–45s |
| T5 | 老板 IP 观点 | 为什么饮料行业"卷价格"走不远 | 30–45s |

### T1 · 知识科普《无菌冷灌装到底先进在哪?》

**目标人群**:饮品同行、餐饮老板、想入行代工的创业者。
**Hook(前 3s)**:一个大多数人不知道的"冷灌装"冷知识。

```
【测试主题】无菌冷灌装到底先进在哪?
【行业】饮料生产 / 饮料代工制造
【目标时长】30-45 秒
【内容形态】知识科普

【脚本要求】
- 前3秒必须抛出抓人的点(冷知识/反常识),不要开场白式"大家好"
- 正文用"为什么先进"展开,讲清 2-3 个关键差异(低温/无菌/保质期/口感)
- 结尾落到"选代工厂要看什么",给一个可执行结论
- 语言口语化,像工厂老师傅在讲,不要宣传片腔
- 30-45秒,约 130-200 字

【期望素材选择逻辑(Agent 需主动匹配)】
- 开头:生产线大景(流水线整体、灌装间全景)
- 正文:无菌灌装工序特写、研发/品控检测、设备细节(管道/阀门/传感器)
- 结尾:产品陈列、工厂环境收尾
- 要求:画面跟着"工艺讲解"走,讲"低温"给冷罐/冷柜,讲"检测"给检测台
```

### T2 · 工厂实力《一条生产线一天能出多少瓶?》

**目标人群**:潜在代工客户、同行参观者。
**Hook**:数字冲击(产能/速度)。

```
【测试主题】一条生产线一天能出多少瓶?
【行业】饮料生产 / 饮料代工制造
【目标时长】30-45 秒
【内容形态】工厂实力展示

【脚本要求】
- 前3秒抛出具体数字(产能/日产量/速度),数字要有冲击力
- 正文展示生产全流程:配料→灌装→封盖→贴标→装箱→码垛
- 结尾"欢迎来厂参观/合作"
- 风格:利落、有节奏,像"进厂一镜到底",少形容词多画面

【期望素材选择逻辑】
- 开头:配料/大罐/产能标识
- 正文:灌装高速特写、封盖、贴标、装箱码垛(一个工序一个镜头)
- 结尾:成品仓库、整装待发、工厂外景
- 要求:突出"自动化程度高",多给机械运转特写,避免静止画面
```

### T3 · 避坑/行业建议《饮料代工选厂,5 个坑别踩》

**目标人群**:想代工的创业/餐饮老板。
**Hook**:直接说"这5个坑我替你踩过了"。

```
【测试主题】饮料代工选厂,5个坑别踩
【行业】饮料生产 / 饮料代工制造
【目标时长】30-45 秒
【内容形态】避坑 / 行业建议(清单式)

【脚本要求】
- 前3秒:一句定调"代工选厂,坑很多,今天说5个"
- 正文:5 个坑,每个一句话,不展开长篇(信息密度高)
- 结尾:一句话总结"认准这三点就够"
- 风格:快节奏、点状输出,像短视频干货博主

【期望素材选择逻辑】
- 开头:工厂外景/洽谈场景
- 正文:按"坑"匹配画面——谈资质给证照/车间,谈成本给配料罐,谈品质给检测
- 结尾:车间或产品特写
- 要求:清单式内容,画面可以多切,不追求单一长镜头
```

### T4 · 产品/案例《客户案例:从代工到自有品牌的第 1 步》

**目标人群**:有产品想法但没产线的品牌方。
**Hook**:真实案例开头("有个客户,去年还只有想法…")。

```
【测试主题】客户案例:从代工到自有品牌的第 1 步
【行业】饮料生产 / 饮料代工制造
【目标时长】30-45 秒
【内容形态】产品 / 案例故事

【脚本要求】
- 前3秒:真实故事钩子,别用"今天给大家介绍"
- 正文:讲清"客户从 0 到 1"的路径(想法→打样→量产→上市)
- 结尾:落到"你也可以",给行动号召
- 风格:有故事感,像讲一个真实发生的转变

【期望素材选择逻辑】
- 开头:配方/打样/实验室
- 正文:小批量试产、灌装、产品成型
- 结尾:成品包装特写、客户收货/陈列
- 要求:案例感强,画面呈现"从无到有"的递进,可用多场景拼贴
```

### T5 · 老板 IP 观点《为什么饮料行业"卷价格"走不远》

**目标人群**:同行、经销商、行业观察者。
**Hook**:老板第一人称观点("我做这行 X 年,卷价格是最蠢的打法")。

```
【测试主题】为什么饮料行业"卷价格"走不远
【行业】饮料生产 / 饮料代工制造
【目标时长】30-45 秒
【内容形态】老板 IP 观点

【脚本要求】
- 前3秒:老板式断言,带身份感("我做了十几年饮料")
- 正文:讲清"卷价格→压缩成本→牺牲品质→死循环"的逻辑
- 结尾:给出观点收尾("与其卷价格,不如卷品质")
- 风格:口语化、有态度、像老板对镜头说话,可以有情绪起伏

【期望素材选择逻辑】
- 开头:老板/负责人画面(如有)、办公室/车间背景
- 正文:生产画面佐证观点(好原料、好设备、品控)
- 结尾:产品/团队画面
- 要求:素材服务于"观点论证",观点类内容画面不苛求一一对应,但基调要"实"
```

## 2. 期望素材逻辑(Agent 选择原则)

- 不是指定具体文件,而是定义 **Agent 应主动选择的素材逻辑**:
  1. **语义匹配**:画面语义与当前文案句子匹配(讲"低温"不切"装箱")
  2. **场景丰富度**:同一段文案尽量用不同机位/场景,避免单场景单调
  3. **避免重复**:同一素材在一条视频里最多出现 1 次(除非刻意强调)
  4. **节奏适配**:Hook 段用动感/近景,讲解段用稳定中景,结尾用开阔收尾
  5. **横竖屏**:按 `video_ratio`(9:16 竖屏为抖音/视频号主流)选择构图合适的素材
  6. **素材来源优先级**:企业真实素材(本地库)> 在线素材(仅当本地无匹配时兜底)

## 3. 统一评分表

> 每条成片按 7 大维度评估,每个维度 **1–5 分**。

### A. 脚本(权重高)

| 分 | 标准 |
|---|---|
| 1 | 开场平淡(你好/大家好),内容空洞,像企业宣传片念稿 |
| 3 | 前 3 秒有一定钩子但不强,内容有价值但偶有冗余 |
| 5 | 前 3 秒抓人,口语化短视频感强,无宣传片腔,内容密而不啰嗦 |

### B. 素材选择

| 分 | 标准 |
|---|---|
| 1 | 画面与文案明显不匹配(讲冷灌装切贴标),或大量重复镜头 |
| 3 | 大部分匹配,少量错配或 1-2 处重复镜头 |
| 5 | 画面与文案高度契合,场景丰富,无错配无重复,横竖屏处理得当 |

### C. 镜头剪辑

| 分 | 标准 |
|---|---|
| 1 | 镜头过长(单镜头 >8s)或过碎(每 1s 一切),机器拼接感强,顺序混乱 |
| 3 | 时长基本合理,转场自然,偶有生硬或顺序小问题 |
| 5 | 镜头节奏与文案同步,转场自然,顺序符合叙事逻辑,无拼接感 |

### D. 配音

| 分 | 标准 |
|---|---|
| 1 | 音色像机器朗读,语速失控,无停顿,情绪平,不像企业内容 |
| 3 | 音色合适,语速正常,有基本停顿,情绪平淡但可接受 |
| 5 | 音色像真人/老板/IP,语速得当,停顿自然,情绪到位 |

### E. 字幕

| 分 | 标准 |
|---|---|
| 1 | 字幕与配音明显不同步,遮挡主体,字号/位置失控,有明显错别字 |
| 3 | 基本同步,位置字号可接受,偶有遮挡或轻微不同步 |
| 5 | 字幕节奏与配音精准同步,位置字号合适,不遮挡主体,零明显错误 |

### F. BGM

| 分 | 标准 |
|---|---|
| 1 | BGM 抢人声(人声听不清),或与主题严重不搭,音量失控 |
| 3 | BGM 音量合适,与主题基本匹配,偶有抢人声 |
| 5 | BGM 恰到好处,烘托不抢人声,与内容情绪匹配 |

### G. 成片(整体)

| 分 | 标准 |
|---|---|
| 1 | 不像可发布视频,需大量人工返工 |
| 3 | 基本可用,需少量返工(改字幕/换个别镜头) |
| 5 | 第一眼像可发布视频,几乎不需返工 |

**总分**:7 维度 × 5 分 = **满分 35 分**。

## 4. 通过线(V1)

> 第一阶段不要求专业剪辑师水平,但必须"能用"。

**硬性通过线(任一不满足 = 直接 FAIL,不进入评分):**
- ✅ 必须生成成功(无渲染失败/任务 error)
- ✅ 时长在 30–45 秒范围内(±5s)
- ✅ 无严重选错素材(讲 A 画面全给 B)
- ✅ 无音画完全无关
- ✅ 无大量重复镜头(同一素材 ≥3 次)
- ✅ 字幕无明显错别字 / 明显不同步

**评分通过线:**
- 总分 ≥ **24 / 35**(平均 ≥3.4)
- 且 **G 成片 ≥ 3 分**(第一眼可用)
- 且 **B 素材选择 ≥ 3 分**(不能有明显错配)
- 且 **E 字幕 ≥ 3 分**

> 达到 = 该主题"V1 通过";未达到 = 按 §6 归因表定位修改点,重跑该主题。

## 5. 失败原因分类(问题归因表)

> 目的:每次生成不满意,能定位到底改哪一层,**不盲目改参数**。

| 现象 | 优先排查层 | 次要排查层 | 备注 |
|---|---|---|---|
| 画面跟文案不匹配 | **素材搜索 / edit plan** | 脚本关键词 | 不直接改 MoneyPrinter |
| 重复镜头多 | **素材索引 / 去重逻辑** | edit plan 选取 | 先查素材多样性 |
| 镜头顺序混乱 | **edit plan(镜头编排)** | 脚本分段 | 顺序由 plan 决定 |
| 镜头过长/过碎 | **剪辑参数(转场/时长)** | edit plan | `video_clip_duration` / transition |
| 转场生硬 | **MoneyPrinter 转场参数** | edit plan | transition-mode |
| 脚本无钩子/宣传片腔 | **Agent 脚本 Prompt** | LLM 温度/模型 | 先改 Prompt 模板 |
| 脚本内容错误/空洞 | **Agent 脚本 Prompt + LLM** | 行业知识库 | 先加领域约束 |
| 音色不合适 | **配音设置(voiceName/voiceService)** | 脚本语气 | 换音色/语速 |
| 语速/停顿问题 | **配音参数(voice_rate)** | 脚本断句 | 先调语速再改脚本 |
| 情绪不到位 | **配音 + 脚本语气** | LLM | 双改,先脚本语气 |
| 字幕不同步/错误 | **字幕生成(whisper/时间轴)** | 配音时长 | 先查 whisper |
| 字幕遮挡主体 | **字幕参数(位置/字号/描边)** | 成片排版 | subtitle_position/font |
| BGM 抢人声 | **BGM 参数(bgm_volume)** | BGM 类型选择 | 先降音量 |
| BGM 不搭 | **BGM 类型选择** | 素材库 | 换 bgm_type |
| 时长超/不足 | **脚本字数** | 剪辑节奏 | 先调脚本字数 |
| 横竖屏构图怪 | **素材构图 + video_ratio** | 素材选择 | 先定 ratio 再选素材 |
| 成片第一眼不像能发 | **整体(脚本+素材+剪辑协同)** | 逐层 | 按 §7 顺序迭代 |

## 6. 迭代顺序(科学调试)

> 第一条视频出来后,**不要所有参数同时改**。按依赖关系由"根"到"末"逐层调:

1. **素材选择**(最底层/影响最大)
   → 画面是观众第一感知;先保证"每句都有对的画面"
2. **镜头顺序**(edit plan)
   → 素材选对后,再看叙事顺序是否通顺
3. **镜头时长 / 转场**(MoneyPrinter 参数)
   → 顺序通顺后再调节奏(长短/转场自然度)
4. **配音**(音色/语速/情绪)
   → 视觉节奏稳了,再听声音
5. **字幕**(同步/位置/字号)
   → 声音定了,字幕才好对时间轴
6. **BGM**(类型/音量)
   → 字幕对齐后,BGM 才不会抢戏
7. **转场细节打磨**(最后微调)

**原因**:
- 素材和镜头顺序是"地基",错配画面再好的配音/字幕都救不回;
- 音画是分层的,先画面后声音,避免同时改造成无法归因;
- 一次只动一层,才能知道"哪一层改对了"。

## 7. 测试执行建议(流程)

1. **准备**:确认素材库 ≥100 条且已按场景打标/语义索引;LLM、Voice Service、MPT 全部就绪
2. **第一轮**:按 T1→T5 顺序各生成 1 条(建议先跑 T1 做冷启动调试)
3. **评分**:同一成片由 2 人独立评分取均值,避免主观偏差
4. **归因**:未达标 → 查 §5 归因表 → 只改对应层 → 重跑该主题
5. **基线固化**:达标后,把"该主题 + 达标时的 Prompt/参数"沉淀为模板基线
