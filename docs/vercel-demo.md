# Vercel 只读演示版

本分支用于公开产品演示。Vercel 配置启用 DEMO_MODE=true，自动使用虚构演示账号及客户信息，所有非读取 API 操作返回 403，不接入真实模型或本机业务数据。

SQLite 仅用于函数实例的临时示例结构，位于系统临时目录，可随时重建，不用于持久化任何用户数据。drizzle 迁移文件通过文件追踪随函数打包。

本机正式版本不启用 DEMO_MODE，继续使用原有账号和数据。不要将演示配置用于正式业务部署。

为适配 Hobby 函数数量上限，演示分支将后台页面与只读 API 分别汇集到两个分发路由；原页面组件保留在 src/lib/demo 中。正式 main 分支不受影响。演示构建使用系统字体回退，不依赖构建时下载 Google Fonts。
