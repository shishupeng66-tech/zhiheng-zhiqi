## 5. 根因分析

### 5.1 证据链

1. **PDF 7 页全部读完**,`X-Api-Resource-Id` 和 `volc.megatts.timbre` **均不出现**(binary grep 二次确认)
2. **clone.py 严格遵循 PDF**,请求头 3/3、请求体 9/9、响应解析 4/4 全对
3. **用户截图证实**模型「豆包声音复刻 2.0」已开通
4. **但豆包仍返回** `HTTP 200 / 业务码 45000030 / "volc.megatts.timbre requested resource not granted"`

### 5.2 推论

`volc.megatts.timbre` 是 **火山引擎网关侧授权表的内部资源 ID**,代表 "一键复刻这个 API 资源维度"。开发者侧既看不到这个字符串,也无法通过请求头/请求体 / HTTP 调用层面去"配对"——这是网关在内部做的权限路由。

控制台"快速接入测试"勾选「豆包声音复刻 2.0」属于 **SDK / 文档层的"模型已开通"维度**;`volc.megatts.timbre` 属于 **网关 key→资源绑定维度**。两个维度的授权是 **分开维护** 的。

通俗说法:
- 「模型已开通」= 这个项目有资格对客户收费
- 「`volc.megatts.timbre`」= 这个具体的 API Key 有资格调用 voice_clone 接口

"模型已开通 + Key 已激活" 不等于 "该 Key 被授权调用 voice_clone 接口"。
