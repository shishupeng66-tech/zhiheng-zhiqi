## 可靠性说明

- 每个 `expected` / `acceptable` 路径都已校验存在于 `video-assets-detailed.json`。
- 黄金答案优先使用 `recommendedCuts` 的起止时间，避免把 `avoidCuts` 当成正确答案。
- 对重复素材设置了 `duplicateRule`，便于后续检测同一重复组是否挤占 Top5。
- 对素材不足场景设置了 `expectedBehavior=insufficient_material`，避免 Agent 强行编造匹配结果。
