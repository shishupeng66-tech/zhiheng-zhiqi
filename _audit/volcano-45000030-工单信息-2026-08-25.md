### 3.3 关键鉴权差异(重要!)

**民间工具使用的鉴权体系是 `X-Api-App-Key + X-Api-Access-Key`(V1 时代,基于 AppID+Token);我们使用的鉴权体系是 `X-Api-Key`(V3 时代,基于 API Key)。**

这是**两套独立的鉴权体系**,对应两个不同的资源授权表:
- 民间工具:鉴权表 = `AppID ↔ {volc.megatts.voiceclone, seed-icl-2.0, ...}`
- 我们:鉴权表 = `API Key ↔ {???, seed-icl-2.0(?), ...}`

→ 即使两个资源名相同(`seed-icl-2.0`),背后鉴权检查的代码路径可能不同。

### 3.4 火山官方回复(用户已获得)

> 2. 不需要 X-Api-Resource-Id

> 4. 当前 45000030 应该检查 **seed-icl-2.0** 资源授权
