# 模板剪辑技巧（第三层 Skill）

> 状态:测试中 · 版本 0.1.0 · id: zhiheng-template-editing-rules
> 作用:使用母版模板替换时的**约束规则库**（能做什么 / 不能做什么 / 怎么替换更好）
> 重要:这不是通用剪辑技巧，是知衡智企在真实测试中踩坑总结的规则。**所有模板替换操作前必须加载本规则。**

## 一、必须做（能做）

1. **母版只读，复制出新草稿**
   - 每次生成 = 复制母版草稿目录 → 替换 → 独立时间戳命名
2. **文字严格等字数替换（EXACT_CHAR_COUNT）**
   - 新文字符数必须 === 原文符数（中文=1，可见标点=1，空格忽略）
   - 已验证：等字数视觉稳定；+1字开始不和谐
3. **花字替换要同步三处**
   - `content` 内的 `text`
   - `styles[].range`（等字数时不变，+字时终点扩展到新长度）
   - `words` 逐字数组（start_time/end_time/text 按新字数重建）
   - 有 `translate_original_text` 也要同步
4. **text_template 的 JSON content 必须保留 styles 结构**
   - content 是 JSON 字符串时：解析 → 改 text → 写回 JSON
   - 禁止覆盖成纯文本（否则模板渲染效果丢失，只剩白色默认字体、字号变大）
5. **搭配组整体替换**
   - 组内所有槽位一起生成、一起替换、一起验收
   - 只改组内一个槽位 = 视觉违和（如"产品+推广"并列词条只改一个）
6. **视频替换只改 6 个字段**
   - `path` / `duration` / `width` / `height` / `type` / `material_name`
   - segment 的 transform / 动画 / 时间点零改动
7. **素材优先竖屏**
   - 从素材索引按语义检索，优先 `verticalCropSuitability=high` 的竖屏素材
8. **替换后结构 diff 验证**
   - 只允许: 文字内容 / 视频引用变化
   - 禁止: 轨道/segment/material_id/template resource_id/动画/transform/timerange/音频/贴纸/特效变化
9. **视觉验收必须人工**
   - 状态: PENDING_USER_REVIEW → 用户在剪映确认 → HUMAN_APPROVED
   - 程序生成成功 ≠ 视觉通过

## 二、绝对不能做（红线）

1. ❌ 自动缩放 scale / 字号（超长字暴露边界，不补救）
2. ❌ 自动换行
3. ❌ 移动位置
4. ❌ 更换模板资源
5. ❌ 从零注入 ScriptTemplate（不研究 resourceId 直建模板）
6. ❌ 把 text_template 的 JSON content 覆盖成纯文本
7. ❌ 修改母版原草稿
8. ❌ 修改 BGM / 贴纸 / 特效 / 转场
9. ❌ 英文 / 数字串 / 中英混排 / 占位符 / 重复词
10. ❌ 超长替换后自动修复视觉
11. ❌ 无合适模板时硬套模板
12. ❌ 程序自动宣布视觉 PASS

## 三、怎么替换更好（技巧）

### 文案层
- 口语化、可信、不浮夸，贴合工厂/产品语境
- 品牌词（河南浩明饮品）与硬实力词（万级洁净车间/无菌冷罐生产线）默认保留，除非客户业务名不同
- 关键词强调槽用 2-6 字高信息密度词条（花字只用于 2-6 字，26 号）
- 词条文本与同组花字核心语义呼应（花字"头部品牌壁垒很高"→ 词条"壁垒高"）
- 并列词条组内同步替换为同一语义域的新词（"产品+推广"→"品质+服务"）
- 开场标题槽用短促有力的词组或短语
- CTA 文案与客户业务名一致，保持原文节奏

### 素材层
- 按槽位语义匹配素材（资质段→公司环境/证书；品质段→品控/检测；交期段→装车/物流；实力段→车间/产线；结尾→装货/接待）
- 优先竖屏素材；横屏素材可进竖版画布（剪映默认 transform），但视觉适配需人工确认
- 替换前确认素材文件真实存在

### 校验层
- 文案生成后逐槽校验字符数，不满足则重写（最多 N 次），仍失败报 CONSTRAINT_UNSATISFIED
- 视频替换后检查 17 个素材文件存在性
- 交付前必须 step5 diff PASS

## 四、历史教训（规则来源）

| 教训 | 后果 | 规则 |
|------|------|------|
| 花字只改 text 不同步 styles | 最后一个字字号/颜色异常 | 同步 styles range + words |
| text_template JSON 覆盖成纯文本 | 模板渲染效果丢失（白色字体、字号变大） | 保留 JSON styles 结构 |
| 搭配组只改一个槽 | 并列词条视觉违和 | 组内整体替换 |
| +1字及以上 | 视觉明显不和谐 | 严格等字数 |
| 超长替换自动修复 | 掩盖真实边界，无法沉淀约束 | 暴露边界，不自动修复 |
| 程序说 PASS | 用户实际看到问题 | 必须人工验收 |
